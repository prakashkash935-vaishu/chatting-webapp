# ❤️ LOVEBOX – Love Mail Web App

LOVEBOX is a full-stack web application created to share private love mails, memories, and special secrets with your loved one.

## ✨ Features

- 🔐 User Registration & Login
- 💌 Send Love Mails
- 📥 Inbox
- ⭐ Starred Mails
- ❤️ My Love
- 📸 Memories with Photo Upload
- 🎁 Private Secrets
- 🔎 Search Mails
- 📱 Responsive Web Interface

## 🛠️ Technologies Used

### Frontend
- HTML5
- CSS3
- JavaScript

### Backend
- Node.js
